# RK3566 Debug 窗口 720p 初始尺寸设计

## 目的

交互式 Debug 程序创建窗口后，将初始窗口尺寸设为 `1280×720`，方便在开发板桌面
进行逐帧、连续播放和鼠标框选调试。

## 范围

- 只改变 OpenCV HighGUI 窗口的初始显示尺寸。
- 不缩放输入帧，不改变 NanoTrack/detector 推理、跟踪框坐标或输出文件尺寸。
- 窗口保持 `WINDOW_NORMAL`，启动后仍允许用户手动缩放。
- 不修改生产版 `ai_alg`，不增加新的命令行或配置项。

## 方案

采用固定默认值：在交互控制接口中定义 `1280×720` 的窗口尺寸常量，
`main.cpp` 在 `namedWindow()` 后调用 `resizeWindow()`。相比新增配置项，这一方案
改动更小，也符合用户只要求默认 720p 的范围。

## 验证

- 单元测试断言窗口宽高常量为 `1280` 和 `720`。
- 主机重新构建并运行现有 CTest。
- 开发板可连接时执行简单原生构建、CTest 和有界启动检查；不做遮挡、重捕或长稳测试。
